# Keybinds Guide

## Programs
- SUPER+Q: Launch Foot (terminal)
- SUPER+E: Launch Nautilus (file manager)
- SUPER+B: Launch Browser (based on the default in XDG)
- SUPER+R: Launch Wofi (application launcher)

## Window Management
### Basic
- SUPER+C: Close window
- SUPER+F: Fullscreen window
- SUPER+V: Toggle floating
- SUPER+P: Toggle pseudotile
### Window Movement
- SUPER+Arrows: Change focused window
- SUPER+Shift+Arrows: Move focused window
- SUPER+J: Toggle split
- SUPER+K: Swap split
- SUPER+Left click: Drag window
- SUPER+Right click: Resize window

## Workspaces
### Normal
- SUPER+Numbers: Change workspace
- SUPER+Shift+Numbers: Move focused window to workspace
- SUPER+Scroll: Scroll through workspaces
- SUPER+Tab: Change workspace layout
### Special
- SUPER+S: Toggle special workspace
- SUPER+Shift+S: Send window to special workspace

## Shell
- PrtScn: Take screenshot
- SUPER+L: Lock
- SUPER+Esc: Power menu
- SUPER+F1: Toggle power saver
